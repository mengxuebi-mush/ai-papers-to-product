## How the posters are built

- `poster.css` holds only the shared base: the 2:3 sheet (24×36 in when printed), the top bar, headline, numerals and the dark question band.
- Each poster lays itself out in its own `<style>` block, built from that paper's content: the shape of the main finding decides the hero, and each "apply" action sits next to the finding it comes from.
- Figures come from my reading notes on each paper; check them against the original before you cite them.
