Apply at workFor any agent with memory
  1. 01

    Count regressions, not just net gain.

    Re-run tasks solved without memory; track flips.

  2. 02

    Store the source with every lesson.

    Link each memory to the run it came from.

  3. 03

    Let the agent check first.

    Give it a tool to open the source run.

  4. 04

    Label what caused success.

    A bare “success” teaches skipped steps.

LimitationsRead the numbers with care
  1. 01Hard tasks.

    On AppWorld, WikiTrace reaches only 75.8%.

  2. 02Lossy extraction.

    Dropped steps stay hidden unless the agent looks.

  3. 03Latency unknown.

    Checking takes time; the cost isn’t reported.

  4. 04Five benchmarks.

    Mostly simulated tasks; other domains untested.
